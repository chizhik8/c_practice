# C Programming Bootcamp Notes

## Що таке мова програмування C

**C** — це універсальна компільована мова програмування, створена для розроблення системного та прикладного програмного забезпечення.

## Коротка історія виникнення

Мова C виникла на початку 1970-х років у дослідницькому центрі **Bell Laboratories** у США. Її створив програміст **Денніс Рітчі**. Основною метою було розроблення зручної та ефективної мови для написання операційної системи **UNIX**.

### Попередники мови C

Розвиток C відбувався поступово:

1. **ALGOL** — одна з перших структурованих мов програмування. Вона вплинула на синтаксис багатьох наступних мов.
2. **CPL** — мова, створена у 1960-х роках для системного програмування, але вона була досить складною.
3. **BCPL** — спрощений варіант CPL, розроблений Мартіном Річардсом у 1967 році.
4. **B** — мова, створена Кеном Томпсоном приблизно у 1969 році на основі BCPL. Її застосовували під час перших етапів розроблення UNIX.
5. **C** — мова, створена Деннісом Рітчі у 1972 році на основі мови B.

Назву **C** обрали тому, що ця мова стала наступним етапом розвитку мови **B**.

### Стандартизація мови

Спочатку єдиного офіційного стандарту C не існувало. Опис мови представили у книзі Браяна Кернігана та Денніса Рітчі *The C Programming Language*, виданій у 1978 році.

Описаний у ній варіант отримав неофіційну назву **K&R C** — за першими літерами прізвищ авторів.

Подальший розвиток мови пов’язаний із появою стандартів:

- **C89** — перший офіційний стандарт ANSI, затверджений у 1989 році;
- **C90** — міжнародна версія стандарту;
- **C99** — додано нові типи даних, однорядкові коментарі та інші можливості;
- **C11** — розширено підтримку багатопотоковості та безпечної роботи;
- **C17** — виправлено недоліки попереднього стандарту;
- **C23** — сучасне оновлення мови з новими синтаксичними й бібліотечними можливостями.

### Вплив мови C

C суттєво вплинула на розвиток програмування. Її синтаксис і принципи використані в багатьох інших мовах:

- C++;
- C#;
- Java;
- JavaScript;
- Objective-C;
- PHP;
- Go;
- Rust.

> **Важливо:** не слід плутати C та C++. Це різні мови програмування. C++ виникла пізніше на основі C та додала підтримку об’єктно-орієнтованого програмування.

C широко застосовують у системному програмуванні, розробленні операційних систем, драйверів, вбудованих пристроїв і програмного забезпечення, для якого особливо важливі швидкість та ефективне використання ресурсів.

## Нотатки

### Директива `#include`

символ # позначає директиву препроцесора;
директиви зазвичай пишуть на початку файла, але вони можуть бути й в інших місцях;

`#include` — це директива препроцесора C для підключення файлів. Вона обробляється ще до компіляції програми. Препроцесор знаходить потрібний файл і умовно підставляє його вміст у програму.

Препроцесор — це етап, який виконується до компіляції програми. Він обробляє рядки, що починаються із символу #.

Існують два основні способи підключення:

- `#include <...>` — переважно для системних і стандартних заголовних файлів;
- `#include "..."` — переважно для власних заголовних файлів.

Після директиви `#include` крапку з комою (`;`) не ставлять.

Процес створення програми можна подати так:

```text
#include → препроцесор → компілятор → компонувальник → програма
```

`#define` - створює константи й макроси;

`#ifdef, #ifndef, #else, #endif` - керують умовною компіляцією.

### Заголовний файл `stdio.h`

У `stdio.h` (*standard input/output*) оголошені функції стандартного введення та виведення:

| Функція | Призначення |
| --- | --- |
| `printf()` | Виводить форматований текст у консоль. |
| `scanf()` | Зчитує форматовані дані з клавіатури. |
| `getchar()` | Зчитує один символ. |
| `putchar()` | Виводить один символ. |
| `puts()` | Виводить рядок і автоматично додає `\n`. |
| `fgets()` | Безпечніше зчитує рядок, зокрема з пробілами. |
| `fopen()` | Відкриває файл. |
| `fclose()` | Закриває файл. |
| `fprintf()` | Записує форматований текст у файл. |
| `fscanf()` | Зчитує форматовані дані з файлу. |
| `fputs()` | Записує рядок у файл. |
| `fgetc()` | Зчитує один символ із файлу. |
| `fputc()` | Записує один символ у файл. |
| `remove()` | Видаляє файл. |
| `rename()` | Перейменовує файл. |

### Керівні послідовності

У мові C символи на кшталт `\n` називаються **керівними послідовностями** (*escape sequences*). Вони починаються зі зворотної похилої риски `\` та позначають символи, які складно або неможливо безпосередньо записати в тексті.

| Послідовність | Значення |
| --- | --- |
| `\n` | Перехід на новий рядок. |
| `\t` | Горизонтальна табуляція. |
| `\r` | Повернення курсора на початок поточного рядка. |
| `\b` | Повернення на один символ назад. |
| `\a` | Звуковий сигнал, якщо термінал його підтримує. |
| `\f` | Перехід на нову сторінку. |
| `\v` | Вертикальна табуляція. |
| `\\` | Символ зворотної похилої риски `\`. |
| `\"` | Подвійні лапки `"`. |
| `\'` | Одинарна лапка `'`. |
| `\?` | Знак питання `?`. |
| `\0` | Нульовий символ із кодом `0`. |

### Специфікатори формату

**Специфікатор формату** — це позначка, яка повідомляє функції, дані якого типу потрібно вивести або зчитати.

```c
int age = 20;
printf("Мені %d років\n", age);
```

У цьому прикладі `%d` замінюється значенням змінної `age`. Тип змінної повинен відповідати специфікатору формату.

### Змінні та типи даних

**Змінна** — це іменована ділянка пам’яті, у якій програма зберігає значення.

Тип змінної визначає:

- які значення можна зберігати;
- скільки пам’яті приблизно займає змінна;
- які операції зі змінною дозволені;
- який специфікатор формату потрібно використовувати.

> **Головне правило:** тип змінної потрібно вибирати відповідно до даних.

#### Цілі числа

| Призначення | Тип | Специфікатор |
| --- | --- | --- |
| Звичайні цілі числа | `int` | `%d` |
| Відносно невеликі цілі числа | `short` | `%hd` |
| Великі цілі числа | `long` | `%ld` |
| Дуже великі цілі числа | `long long` | `%lld` |

#### Символьний тип

Для зберігання одного символу використовують тип `char`, а для його виведення — специфікатор `%c`.

```c
char symbol = '7'; // символ
int number = 7;    // число
```

#### Рядки

У мові C немає окремого типу для рядків. Рядок зберігають як масив символів `char`, що закінчується нульовим символом `\0`, а для його виведення використовують специфікатор `%s`.

```c
char text[] = "Hello"; // рядок
printf("%s\n", text); // Hello
```

#### Дробові числа

Для зберігання дробових чисел можна використовувати тип `float`. У функції `printf()` йому відповідає специфікатор `%f`.
