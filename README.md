C Programming Bootcamp Notes.

C — це універсальна компільована мова програмування, створена для розроблення системного та прикладного програмного забезпечення

Мова C виникла на початку 1970-х років у дослідницькому центрі Bell Laboratories у США.
Її створив програміст Денніс Рітчі. Основною метою було розроблення зручної та ефективної мови для написання операційної системи UNIX.
Попередники мови C
Розвиток C відбувався поступово:
    1. ALGOL
    Одна з перших структурованих мов програмування. Вона вплинула на синтаксис багатьох наступних мов.
    2. CPL
    Мова, створена у 1960-х роках для системного програмування, але вона була досить складною.
    3. BCPL
    Спрощений варіант CPL, розроблений Мартіном Річардсом у 1967 році.
    4. B
    Мова, створена Кеном Томпсоном приблизно у 1969 році на основі BCPL. Її застосовували під час перших етапів розроблення UNIX.
    5. C
    На основі мови B Денніс Рітчі у 1972 році створив нову мову, яка отримала назву C.
Назва C була обрана тому, що ця мова стала наступним етапом розвитку мови B.

Спочатку єдиного офіційного стандарту C не існувало. Опис мови був представлений у книзі Браяна Кернігана та Денніса Рітчі «The C Programming Language», виданій у 1978 році.
Описаний у ній варіант отримав неофіційну назву K&R C — за першими літерами прізвищ авторів.
Подальший розвиток мови пов’язаний із появою стандартів:
- C89 — перший офіційний стандарт ANSI, затверджений у 1989 році;
- C90 — міжнародна версія стандарту;
- C99 — додано нові типи даних, однорядкові коментарі та інші можливості;
- C11 — розширено підтримку багатопотоковості та безпечної роботи;
- C17 — виправлено недоліки попереднього стандарту;
- C23 — сучасне оновлення мови з новими синтаксичними й бібліотечними можливостями.

C суттєво вплинула на розвиток програмування. Її синтаксис і принципи використані в багатьох інших мовах:
- C++;
- C#;
- Java;
- JavaScript;
- Objective-C;
- PHP;
- Go;
- Rust.
Особливо важливо не плутати C та C++. Це різні мови програмування. C++ виникла пізніше на основі C та додала підтримку об’єктно-орієнтованого програмування.

C широко застосовується у системному програмуванні, розробленні операційних систем, драйверів, вбудованих пристроїв і програмного забезпечення, для якого особливо важливі швидкість та ефективне використання ресурсів

# Notes

    #include — це команда препроцесора C підключення файлів. Вона виконується ще до компіляції програми. 
    Препроцесор знаходить файл і умовно підставляє його вміст. 
    Існують два основні способи підключення: <...> і "...". Кутові дужки використовують переважно для системних і стандартних заголовків. 
    Подвійні лапки використовують для власних заголовних файлів. 
    І ще одна важлива деталь: після #include не ставиться ;
    Процес приблизно такий: #include → препроцесор → компілятор → компонувальник → програма

    У stdio.h (standard input/output) оголошені функції стандартного введення та виведення:
    `printf()` Виводить форматований текст у консоль. 
    `scanf()` Зчитує форматовані дані з клавіатури.
    `getchar()` Зчитує один символ.
    `putchar()` Виводить один символ.
    `puts()` Виводить рядок і автоматично додає `\n`. 
    `fgets()` Безпечніше зчитує рядок, зокрема з пробілами. 
    `fopen()` Відкриває файл. 
    `fclose()` Закриває файл. 
    `fprintf()` Записує форматований текст у файл. 
    `fscanf()` Зчитує форматовані дані з файлу. 
    `fputs()` Записує рядок у файл. 
    `fgetc()` Зчитує один символ із файлу. 
    `fputc()` Записує один символ у файл. 
    `remove()` Видаляє файл. 
    `rename()` Перейменовує файл.

    У мові C символи на кшталт \n називаються керівними (escape) послідовностями. 
    Вони починаються зі зворотної похилої риски \ та позначають символи, які важко або неможливо безпосередньо записати в тексті.
    `\n` Перехід на новий рядок
    `\t` Горизонтальна табуляція
    `\r` Повернення курсора на початок поточного рядка
    `\b` Повернення на один символ назад
    `\a` Звуковий сигнал, якщо термінал його підтримує
    `\f` Перехід на нову сторінку
    `\v` Вертикальна табуляція
    `\\` Символ зворотної похилої риски `\`
    `\"` Подвійні лапки `"`
    `\'` Одинарна лапка `'`
    `\?` Знак питання `?`
    `\0` Нульовий символ із кодом `0`

        Специфікатор формату — це позначка, яка повідомляє функціям, якого типу дані потрібно вивести або зчитати.
        int age = 20;
        printf("Мені %d років\n", age);
    Тут %d замінюється значенням змінної age.
    Тип змінної повинен відповідати специфікатору.
    
    Змінна — це іменована ділянка пам’яті, у якій програма зберігає значення.
    Тип визначає:
        - які значення можна зберігати;
        - скільки пам’яті приблизно займає змінна;
        - які операції з нею дозволені;
        - який специфікатор формату потрібно використовувати.
    Головне правило: тип змінної потрібно вибирати відповідно до даних.

    > Цілі числа - int (тип) - %d (специфікатор)
    для відносно невеликих цілих чисел - short - %hd
    більші цілі числа - long - %ld
    для дуже великих цілих чисел: - long long - %lld

    > Символьний тип - char - %c
    char symbol = '7'; — символ
    int number = 7; — число

    > Дробові типи - float - %f
